# salary-predictor
Salary Predictor is a web application that estimates a person's salary based on their years of experience. The user enters their experience in a simple form, the value is scaled with a saved StandardScaler, and a trained Linear Regression model predicts the salary, which is shown on the page in rupees (₹). The app is built with Flask for the backend, HTML and CSS for the interface, and scikit-learn for the machine learning model.
A Flask web app that predicts salary from years of experience using a Linear Regression machine learning model.
